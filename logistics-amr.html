The challenge

Navigate six warehouse destinations through constrained corridors and around four moving obstacles. Nav2 provides global path planning and built-in DWB path following; the custom node adds short-horizon motion-aware supervision.

What I implemented

The Python Simulation Master groups LiDAR detections across scans, estimates tracked-obstacle velocities, and extrapolates short-term motion using a constant-velocity model. It evaluates a 25 × 25 grid of candidate linear/angular velocity commands (625 combinations), simulates trajectories for 3 seconds at 0.2-second steps, and selects a feasible command that stays close to Nav2's request. The configured control period is 0.1 seconds (10 Hz).

The selected velocity is passed through the configured safety chain before Gazebo executes it. Nav2 independently updates costmaps with LiDAR data and can replan the global route; the custom supervisor does not replace Nav2's global planner.

How the results were measured

During a full mission, ROS 2 rosbag2 recorded odometry, LiDAR, global plans, system logs and navigation status. A Python analysis script extracted the measurements:

  • 31.94 m travelled: summing consecutive recorded odometry position increments, with small movements and large jumps filtered.
  • 155 s mission duration: subtracting the recorded mission-start and completion log timestamps.
  • 6/6 goals: counting distinct goal-verification messages published by the mission controller.
  • 3.26 cm mean path error: averaging cross-track error samples reported in the controller's telemetry.
  • 24.54 ms mean and 95 ms maximum DWA time: aggregating computation times reported in the same telemetry.
  • 155 paths / 150 geometry changes: counting /plan messages and differences between rounded successive path point sets.

Limitations: A single successful simulation run does not establish reliability across repeated trials, superiority over standard Nav2, or collision-free operation. A 0.120 m minimum LiDAR reading measures sensor range, not robot-body clearance. The 95 ms maximum compute time is close to the 100 ms control interval.
