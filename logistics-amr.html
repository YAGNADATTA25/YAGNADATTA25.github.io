PROJECT 02 / MOBILE ROBOTICS

Multi-goal logistics AMR

Warehouse waypoint navigation with predictive local planning and a directional safety override.

ROS 2Nav2DWA

The question

How can an autonomous mobile robot visit multiple warehouse destinations while reacting to obstacles?

The approach

The repository describes waypoint dispatch through Nav2, predictive Dynamic Window Approach trajectory evaluation and a directional LiDAR safety layer. Telemetry includes cross-track error, heading deviation and distance to goal.
